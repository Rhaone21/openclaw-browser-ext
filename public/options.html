OpenClaw Browser Relay

Connect OpenClaw AI agents to your browser

Getting Started

This extension enables OpenClaw AI agents to control your browser via Chrome DevTools Protocol (CDP).

1. Start OpenClaw Gateway on your machine
2. Configure the connection settings below
3. Click the extension icon on any tab to attach

Documentation: docs.openclaw.ai

Connection Settings

Default: 18792. Must match your OpenClaw Gateway configuration.
Get this from your OpenClaw Gateway configuration (gateway.auth.token or OPENCLAW_GATEWAY_TOKEN env var).
